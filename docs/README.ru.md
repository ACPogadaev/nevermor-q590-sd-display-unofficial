# Nevermor Q590-SD / SD-Q590 Display 1.3.1 — независимое неофициальное ПО

Проект является независимым неофициальным программным обеспечением и не связан с Nevermor. Все товарные знаки принадлежат их владельцам. Использование осуществляется на собственный риск. Перед применением на реальном оборудовании необходимо проверить совместимость и требования производителя.

## Одна установка

Исправление 1.3.1: ярлыки создаются через Unicode-интерфейс Windows IShellLinkW/IPersistFile в отдельном STA-потоке. Русские имена файлов и пути не преобразуются через ANSI. Ошибка создания ярлыка больше не прерывает установку приложения и регистрацию удаления; в журнале будет предупреждение и путь прямого запуска. Повторная установка поверх незавершённой 1.3 сохраняет настройки и использует уже установленный PawnIO.

Запустите NevermorDisplay-1.3.1-Setup.exe, подтвердите обычный запрос прав Windows и нажмите «Установить / обновить». Приложение, библиотека датчиков и официальный подписанный драйвер PawnIO 2.2.0 находятся внутри одного файла. Установка не скачивает компоненты. AIDA64, Digital, LibreHardwareMonitor как отдельная программа, Python и другие дополнительные программы не нужны. Используется .NET Framework 4.7.2 или новее, встроенный в поддерживаемые Windows 10/11.

PawnIO — готовый сторонний драйвер namazso, а не собственный драйвер проекта. Установщик включает его неизменённый официальный дистрибутив. Он автоматически запускает установку подписанной обычной версии через документированные параметры `-install -silent`. Unrestricted-версия не используется. Контрольная сумма SHA-256 и подпись Windows проверяются. Совместимая версия 2.2 или новее, уже установленная в системе, сохраняется и используется повторно.

Сам контроллер и наш общий установщик пока не имеют коммерческой подписи издателя. Подпись namazso относится к встроенному оригинальному установщику PawnIO и его компонентам. Не следует путать её с подписью всего нашего пакета.

Приложение размещается в `%ProgramFiles%\Nevermor Display`. Ярлыки появляются в меню «Пуск», запись удаления — в установленных приложениях Windows. Настройки и диагностика находятся в `%LOCALAPPDATA%\NevermorDisplay`. Предыдущие переносимые папки и их настройки сохраняются. Работавшая предыдущая Nevermor Display закрывается через её штатный сигнал выхода. Ранее включённый автозапуск переводится на новую установленную копию; выключенный автозапуск не включается автоматически.

## Первая проверка

1. Закройте Digital и AIDA64 через их меню выхода, чтобы исключить одновременный опрос аппаратных датчиков. Защиту Windows оставьте включённой.
2. Установите пакет. Если встроенный установщик драйвера сообщает, что нужна перезагрузка, сохраните работу и перезагрузите Windows. Автоматической перезагрузки нет.
3. Нажмите «Запустить приложение» или откройте ярлык в меню «Пуск». Для CPU/RPM нужны права администратора. При обычном ручном запуске приложение само запросит их через UAC.
4. По умолчанию сверху выводится загрузка CPU, снизу — температура CPU. Выберите нужные показатели и интервал, нажмите «Сохранить».
5. Для оборотов выберите сверху «Обороты выбранного вентилятора». В списке выберите нужный датчик CPU Fan. Библиотека поддерживает Nuvoton NCT6686D, но соответствие каналов вентиляторов именно на ASRock B850 Riptide WiFi требует проверки по BIOS или известным показаниям. Другой вентилятор за CPU не выдаётся автоматически.
6. Включите автозапуск в окне приложения, если он нужен. При настройке из повышенного процесса используется планировщик Windows с правами текущего пользователя; повторные запросы UAC при входе не нужны.

Дисплей аппаратно ограничен четырьмя цифрами сверху и двумя снизу. Подписи на самом дисплее изменить нельзя. Часы поддерживают формат Windows, 12 часов и 24 часа. При отсутствии выбранных данных отправка приостанавливается; ложные нули не выводятся, предыдущие цифры могут оставаться.

## Нагрузка

Опрос выполняется отдельным потоком с заданным интервалом, одновременно запускается не более одного опроса. Открываются только выбранные группы датчиков, постоянной графической отрисовки в трее нет. Загрузка CPU и память читаются штатными функциями Windows, NVIDIA — через уже установленный драйвер GPU. AIDA64 и отдельная служба периодического сбора показателей не запускаются. Для CPU/RPM обычно достаточно интервала 2–5 секунд. Фактическое время одного опроса и память видны в окне программы.

## Ошибки и удаление

Если данные недоступны, используйте меню значка в трее → «Сохранить диагностику». Путь: `%LOCALAPPDATA%\NevermorDisplay\diagnostics.txt`. Журнал установки: `%LOCALAPPDATA%\NevermorDisplay\setup.log`. Для восстановления запустите единый установщик повторно. Изменять Defender, Secure Boot, целостность памяти или проверку подписей не требуется; установщик этого не делает.

Удаление доступно в приложениях Windows и через ярлык «Удалить Nevermor Display». Настройки сохраняются. По умолчанию общий PawnIO сохраняется, поскольку им могут пользоваться другие программы. Если драйвер был добавлен именно нашим пакетом и не нужен другим программам, в мастере удаления можно выбрать его удаление вместе с приложением. Предустановленный другой программой драйвер мастер не удаляет. PawnIO может отображаться как отдельный компонент в списке приложений Windows, хотя устанавливается автоматически одним нашим мастером.

## Проверка и ограничения

Проверены сборка, настройки, часы, числовой протокол дисплея, пауза, безопасная распаковка установочного пакета, подпись встроенного установщика драйвера, обработка его ошибок и обновление файлов с восстановлением предыдущей копии при ошибке переноса. Проверена установка версии 1.3.1: температура CPU считывалась корректно, после перезагрузки восстановилась передача на физический дисплей. Соответствие канала вентилятора CPU и работа автозапуска после реального входа в Windows ещё требуют проверки.

Исходники приложения находятся в `source`, установщика — в `installer`. Лицензия контроллера — MIT, LibreHardwareMonitor 0.9.6 — MPL 2.0. Полные зависимости и лицензии — в `dependencies.json` и `licenses`.

Источники: [LibreHardwareMonitor 0.9.6](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases/tag/v0.9.6), [PawnIO](https://pawnio.eu/), [условия распространения официального установщика](https://github.com/namazso/PawnIO.Modules/wiki/Using-PawnIO-Modules), [параметры установки и контрольная сумма Microsoft winget](https://github.com/microsoft/winget-pkgs/blob/master/manifests/n/namazso/PawnIO/2.2.0/namazso.PawnIO.installer.yaml).

## Почему блокируется Digital

Подтверждённая причина и отличие от сбоя USB описаны в [DIGITAL-BLOCKING.ru.md](DIGITAL-BLOCKING.ru.md). После установки 1.3.1 температура CPU стала читаться корректно; после перезагрузки также заработал физический дисплей. Соответствие канала вентилятора CPU и работа автозапуска после входа ещё требуют отдельной проверки.
