# Nevermor Q590-SD / SD-Q590: независимое неофициальное ПО дисплея кулера

**Проект является независимым неофициальным программным обеспечением и не связан с Nevermor. Все товарные знаки принадлежат их владельцам. Использование осуществляется на собственный риск. Перед применением на реальном оборудовании необходимо проверить совместимость и требования производителя.**

Nevermor Display — самостоятельная переносимая программа управления дисплеем башенного кулера **Nevermor Q590-SD**, который также встречается под названием **SD-Q590**. Позволяет выбирать числовые показатели вместо штатных температуры CPU и оборотов.

## Скачать и запустить

Скачайте готовый [NevermorDisplay-v1.1.0-win-x64.zip](https://github.com/ACPogadaev/nevermor-q590-sd-display-unofficial/releases/download/v1.1.0/NevermorDisplay-v1.1.0-win-x64.zip) со [страницы релиза](https://github.com/ACPogadaev/nevermor-q590-sd-display-unofficial/releases/tag/v1.1.0). Кнопка GitHub **Code → Download ZIP** скачивает исходники.

1. Распакуйте весь архив в папку с правом записи.
2. Закройте штатную **Digital / DeviceDriver.exe** через её значок в трее.
3. Запустите `NevermorDisplay.exe`; все DLL должны оставаться рядом.
4. Выберите верхний и нижний показатели, интервал и нажмите **Сохранить**.

Windows 10/11 x64, .NET Framework 4.7.2 или новее. Установка не требуется. Крестик скрывает окно в трей, двойной щелчок по значку открывает настройки. **Выход** завершает программу.

## Что можно выводить

- Температуру и загрузку CPU/GPU, частоты в МГц.
- Использование RAM в процентах или целых ГБ.
- Обороты выбранного вентилятора материнской платы.
- Часы: формат Windows, 12 часов либо 24 часа.
- Секунды часов в нижнем поле или дату ДДММ сверху.
- Постоянное число, введённое вручную.

Верхнее поле: 0–9999, нижнее: 0–99. 100% в нижнем поле превращается в 99. Физические подписи SPEED/TEMP/USAGE и °C не меняются. Произвольный текст и изображения команда не поддерживает.

Для отображения 1:15 вместо 13:15: верхнее поле → **Время**, **Формат времени → 12 часов**, **Сохранить**. AM/PM показывается в окне, на кулер отправляются только цифры. Полночь и полдень в 12-часовом формате кодируются как 1200. Для отдельных секунд выберите **Секунды часов** снизу и период 1 секунда. Дата 7 октября передаётся числом 0710. Отображение ведущих нулей и разделителей зависит от прошивки.

## Датчики и права

Для температуры/частоты CPU и оборотов нажмите **Запустить от администратора** и подтвердите запрос Windows. Наличие датчиков зависит от материнской платы и доступности драйвера. Если вентиляторы названы `Fan #1`, `Fan #2`, выберите нужный вручную; программа автоматически выбирает только датчик с CPU в имени.

Загрузка CPU и RAM используют счётчики Windows. NVIDIA читается через установленный драйвер, без общего обхода всех датчиков. При наличии NVIDIA в списке показываются карты NVIDIA; другой тип GPU используется через LibreHardwareMonitor, когда путь NVIDIA недоступен.

Если значение недоступно, в окне будет «—», отправка приостановится; предыдущие цифры на кулере могут оставаться.

## Автозапуск

Отметьте **Автозапуск при входе в Windows**, при необходимости **При автозапуске сразу в трей**, затем **Сохранить**. Обычный запуск добавляет значение в HKCU Run; запуск от администратора создаёт задачу планировщика для текущего пользователя с повышенными правами и задержкой 10 секунд после входа. Пароль не сохраняется.

Сначала разместите папку программы в постоянном месте. Автозапуск старой Digital отключайте отдельно, если он включён. При обнаружении `DeviceDriver.exe` новая программа приостанавливает передачу, не завершает чужие процессы. Для отключения повышенного автозапуска запустите приложение от администратора, снимите галочку и сохраните.

## Нагрузка и файлы

Один процесс, приоритет ниже обычного, опрос раз в 1–60 секунд. Открываются только выбранные группы мониторинга; отрисовка в трее выключена. При обычной работе нет сетевых запросов. Для большинства показателей достаточно 2–5 секунд.

Короткий замер исходной локальной версии при CPU load + GPU temperature каждые 2 секунды: около 0,0022% общего CPU и 72,58 МБ памяти. Это не измерение всех датчиков и не гарантия для любой системы; [условия и ограничения](VALIDATION.md).

Настройки сохраняются рядом с EXE в `settings.xml`. Меню трея **Сохранить диагностику** создаёт `diagnostics.txt`; ошибки запуска — `last-error.txt`. В архиве релиза используются стандартные настройки; личный XML автора не публикуется.

## Дисплей определяется как USB Gaming Keyboard или CH340?

Для исследованной Digital 1.0.0.3 используется HID **VID 1A2C / PID 4E84**, Usage Page FF01, Usage 1, Report 7. Windows может назвать интерфейс **USB Gaming Keyboard / SEMICO**. Программа проверяет дополнительные параметры HID перед передачей.

Последовательный **CH340 / CH341, VID 1A86 PID 7523, COM3** в восстановленном пути обновления этого дисплея не участвует. Нужна HID-программа, а не настройка скорости COM-порта. Другие аппаратные ревизии пока не проверены.

## Сборка из исходников

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\test.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

Зависимости скачиваются с официального NuGet при сборке. Используется компилятор .NET Framework из Windows; Visual Studio не требуется. Готовая программа появится в `build/app`, ZIP — в `dist`. Самопроверка не отправляет USB-команды и не включает автозапуск.

Проект независимый, не является официальным ПО Nevermor. Совместимость передачи подтверждена на одном Q590-SD. Показатели CPU/RPM с публичной библиотекой и фактический вход Windows с автозапуском ещё требуют проверки. Подробности: [протокол](PROTOCOL.md) и [проверки](VALIDATION.md).
